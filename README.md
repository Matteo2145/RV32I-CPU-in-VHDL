# RV32I-CPU-in-VHDL

## Description
This project aims to create an RV32I CPU in VHDL, starting from the basic functionalities up to more complex features.
The project has started as a personal work, because I wanted to improve my skills in Hardware Description Language and to obtain a deeper undesrtanding of CPU architecture.

## Features
-*RV32I Instruction Set*
-*Pipelining* (in progress)
-*FP operations* (coming soon)

## Software
I use Xilinx Vivad 2022.2
